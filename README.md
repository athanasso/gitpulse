# GitPulse ⚡🐙

> A high-performance, developer-first mobile GitHub client built with **React Native**, **Expo 58**, and **TypeScript**. Engineered for developers who want instantaneous repository search, fast syntax-highlighted code browsing with line numbers, live pull request diff inspection, GitHub Actions workflow logs, and interactive annual contribution heatmaps on mobile.

---

## 🎯 Key Features

1. **⚡ Fast Repositories Hub**:
   - Filter by language (TypeScript, JavaScript, Python, etc.) and search across all public & private repositories.
   - Star counts, fork counts, active branch tracking, and visibility badges.

2. **🌲 Full Code & Tree Explorer**:
   - Directory navigation with breadcrumb history.
   - Syntax-highlighted code viewer with line numbers and byte size tracking.
   - Inline formatted README viewer.

3. **🔀 Unified Diffs & Commits**:
   - Commit history log with SHA badges and committer avatars.
   - Line-by-line diff inspection with additions (`+` green) and deletions (`-` red).

4. **💬 Pull Requests & Issue Tracker**:
   - Real-time PR/Issue status (Open, Closed, Merged).
   - Milestone tracking, label tags, and comment feeds.

5. **⚡ GitHub Actions & CI/CD Pipeline**:
   - Live workflow run status (✅ Success, ❌ Failure, ⏳ Queued).
   - Run duration, branch triggers, and commit SHA tracking.

6. **📊 52-Week Contribution Heatmap**:
   - Interactive annual commit matrix with color levels (0-4).
   - Current streak and longest streak calculations with daily metric inspector.

7. **🔔 Triage Inbox**:
   - Fast notification triage: filter by PR reviews, issues, and commit mentions.
   - One-tap "Mark all read".

8. **📱 Device Sleep Prevention**:
   - `expo-keep-awake` keeps the display awake during long code reviews and log inspections.
